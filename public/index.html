      How to Play

      1. Create a game to get a room code, or join with a code your opponent shared.
      2. Both players secretly enter up to three two-word phrases at the same time. The second word of each is typed into a hidden password field.
      3. Only the first word of each phrase is shown to your opponent.
      4. Both players then simultaneously try to guess each other's hidden second words.
      5. Each phrase that gets correctly guessed earns its owner 1 point (up to 3 points per round) — so a phrase that's too easy to guess costs you. A full game is 5 rounds.
      6. After 5 rounds, the player with the higher score wins!

      Reset Scores?

      This will reset both players' scores to zero. This cannot be undone.
